01

Masuk & Beranda

Karyawan masuk sekali, lalu semua yang penting hari ini ada di satu layar: shift, tombol absen, saldo cuti, dan pengajuan yang sedang berjalan.

4 layar
1KARYAWAN · APK ANDROID

Login Karyawan

Masuk memakai email & kata sandi. Satu akun hanya boleh aktif di satu perangkat — login di HP lain otomatis mengeluarkan sesi lama.

→
2KARYAWAN · APK ANDROID

Kredensial Terisi

Validasi langsung di form; kata sandi bisa ditampilkan/disembunyikan. Sesi tersimpan aman di Keystore perangkat.

→
3KARYAWAN · APK ANDROID

Beranda Karyawan

Shift hari ini, jam masuk, tombol Clock In besar, peringatan jarak ke site, dan kartu pintas Cuti / Lembur / Reimburse.

→
4KARYAWAN · APK ANDROID

Pengajuan Berjalan

Semua pengajuan yang belum final tampil di bawah Beranda lengkap dengan statusnya (Menunggu HRD, Perlu revisi, dst).

02

Absensi Clock-in / Clock-out

Foto selfie + GPS + stempel server anti-manipulasi. Di luar radius site tetap bisa absen, tetapi wajib memberi alasan dan otomatis ditandai untuk ditinjau HRD.

12 layar
1KARYAWAN · APK ANDROID

Kamera Absen

Pilih Clock In / Clock Out, ambil foto. Kamera dibuka dari tombol besar di Beranda atau tombol ⊕ di bilah bawah.

→
2KARYAWAN · APK ANDROID

Pratinjau + Watermark

Nama, NIK, waktu server (bukan jam HP), site penempatan + status radius, koordinat, akurasi GPS, dan kode unik ditanam ke foto — bukti yang tidak bisa diedit.

→
3KARYAWAN · APK ANDROID

Deteksi Luar Radius

Jarak ke site dihitung saat itu juga. Di luar radius → form alasan wajib muncul sebelum bisa mengirim.

→
4KARYAWAN · APK ANDROID

Alasan Diisi

Alasan tersimpan bersama absensi dan tampil di dashboard HRD saat review.

→
5KARYAWAN · APK ANDROID

Absen Tercatat

Server menerima foto + telemetri, menghitung status (ON_TIME / LATE / OUT_OF_ZONE) dan skor risiko secara otomatis.

→
6KARYAWAN · APK ANDROID

Beranda Setelah Clock-in

Jam masuk tercatat, tombol berubah menjadi Clock Out. Tidak bisa clock-in dua kali.

→
7KARYAWAN · APK ANDROID

Clock Out

Sore hari: alur yang sama, tombol Clock Out sudah terpilih otomatis.

→
8KARYAWAN · APK ANDROID

Pratinjau Clock Out

Watermark kedua dengan kode unik baru — setiap foto punya nonce server yang kedaluwarsa dalam ±90 detik.

→
9KARYAWAN · APK ANDROID

Absensi Hari Ini Selesai

Tombol terkunci setelah clock-out. Status hari itu siap masuk rekap payroll.

→
10KARYAWAN · APK ANDROID

Riwayat Absensi

Jam masuk/pulang dan label status per hari: Tepat waktu, Terlambat, Luar zona, Tidak hadir.

→
11HRD/ADMIN · DASHBOARD WEB

Peta Harian (Monitoring HRD)

Titik absen semua karyawan di peta jalan (OpenStreetMap), berwarna sesuai status. Filter tanggal / kanal / status, klik titik untuk detail.

→
12HRD/ADMIN · DASHBOARD WEB

Review Anomali (HRD)

8 pemeriksaan otomatis (GPS palsu, koordinat statis, foto diulang, dll) → skor risiko. HRD memutuskan: Wajar, Perlu klarifikasi, atau Terbukti curang.

03

Absensi Offline (Tanpa Sinyal)

Lokasi kerja tanpa sinyal tetap bisa absen: foto + GPS disimpan di perangkat, lalu terkirim otomatis begitu online. Batas sinkron 72 jam — lewat dari itu koreksi lewat HRD. Layar di bawah dari PWA; APK Android memakai alur yang sama dengan antrian SQLite.

8 layar
1KARYAWAN · PWA (iOS)

Sebelum Sinyal Hilang

Shift hari ini, tombol Clock In, dan status radius. Halaman Absen, Beranda, dan Riwayat sudah tersimpan di cache aplikasi sejak dibuka saat online.

→
2KARYAWAN · PWA (iOS)

Kamera Saat Offline

Koneksi terputus di lokasi kerja. Kamera dan GPS tetap berjalan karena keduanya tidak butuh internet.

→
3KARYAWAN · PWA (iOS)

Stempel Kode OFFLINE

Server tidak terjangkau, jadi tidak ada kode dari server: stempel memakai kode lokal OFFLINE-xxxx dan jam perangkat. Nama, NIK, site + status radius, koordinat, dan akurasi GPS tetap tertanam di foto.

→
4KARYAWAN · PWA (iOS)

Tersimpan di Antrian Perangkat

Absen masuk antrian perangkat. Badge “belum tersinkron”, rincian tanggal/jam, dan peringatan batas 72 jam langsung tampil. Clock-in kedua hari itu diblokir walau yang pertama masih mengantri.

→
5KARYAWAN · PWA (iOS)

Online → Tersinkron Otomatis

Begitu online dan layar Absen dibuka, antrian terkirim sendiri (dicek saat dibuka, saat sinyal kembali, dan tiap 15 detik). Server memvalidasi jam perangkat dan menandai selisih jam yang mencurigakan untuk HRD.

→
6KARYAWAN · PWA (iOS)

Clock Out Offline

Sore hari tanpa sinyal lagi: alur yang sama, dengan kode OFFLINE baru di stempel.

→
7KARYAWAN · PWA (iOS)

Absensi Hari Ini Selesai

Clock-in (sudah di server) + clock-out (di antrian) dihitung lengkap — kamera terkunci tanpa menunggu sinkron.

→
8KARYAWAN · PWA (iOS)

Tercatat Sesuai Jam Foto

Setelah sinkron, jam masuk/pulang tercatat sesuai waktu foto diambil — bukan waktu sinkron — dan status dihitung dari jam itu (contoh ini diambil 17.26, di luar jam shift Office).

04

Klarifikasi Absensi

Absensi mencurigakan tidak langsung dihukum — HRD meminta penjelasan, karyawan wajib menjawab dari aplikasi sebelum bisa mengajukan apa pun.

5 layar
1HRD/ADMIN · DASHBOARD WEB

HRD Minta Klarifikasi

Dari menu Review Anomali, HRD menandai satu atau banyak absensi sekaligus (bulk) sebagai Perlu Klarifikasi.

→
2KARYAWAN · APK ANDROID

Banner di Beranda

Karyawan melihat peringatan merah: pengajuan cuti/lembur/reimbursement diblokir sampai klarifikasi dijawab.

→
3KARYAWAN · APK ANDROID

Form Klarifikasi

Tanggal absensi yang dipertanyakan ditampilkan; karyawan menulis penjelasan minimal 10 karakter.

→
4KARYAWAN · APK ANDROID

Penjelasan Ditulis

Contoh: absen dari gerbang site klien karena inspeksi. Tombol kirim aktif setelah syarat terpenuhi.

→
5KARYAWAN · APK ANDROID

Klarifikasi Terkirim

Blokir pengajuan otomatis dibuka. Jawaban tercatat di audit log dan terlihat HRD.

05

Pengajuan Cuti

Saldo cuti dihitung otomatis (kuota tahunan, sisa tahun lalu, masa kedaluwarsa). Karyawan mengajukan → HRD menyetujui → hasil kembali ke aplikasi.

9 layar
1KARYAWAN · APK ANDROID

Form Cuti + Saldo

Sisa cuti tahun berjalan tampil di atas form. Jenis: Tahunan, Sakit, Izin, Melahirkan, Penting, Unpaid.

→
2KARYAWAN · APK ANDROID

Pilih Tanggal

Pemilih tanggal native Android; tanggal mulai/selesai divalidasi (tidak boleh mundur).

→
3KARYAWAN · APK ANDROID

Form Terisi

Rentang tanggal + alasan. Hari libur & akhir pekan tidak memotong kuota.

→
4KARYAWAN · APK ANDROID

Estimasi Hari Dipotong

Aplikasi menghitung hari kerja yang akan dipotong sebelum dikirim — tidak ada kejutan.

→
5KARYAWAN · APK ANDROID

Cuti Terkirim

Status PENDING_HRD; saldo langsung ditahan (hold) agar tidak bisa dipakai ganda.

→
6KARYAWAN · APK ANDROID

Menunggu HRD

Di Riwayat › Cuti pengajuan tampil dengan status Menunggu HRD.

→
7HRD/ADMIN · DASHBOARD WEB

Antrian Approval (HRD)

HRD melihat semua pengajuan, menyetujui / menolak / minta revisi, juga bisa aksi massal. Kolom Detail pengajuan menampilkan rentang tanggal & total hari cuti langsung di baris — tanpa buka layar lain.

→
8KARYAWAN · APK ANDROID

Notifikasi Keputusan

Begitu HRD memutuskan, notifikasi muncul di aplikasi lengkap dengan nama pemberi keputusan.

→
9KARYAWAN · APK ANDROID

Tercatat Disetujui

Status berubah menjadi Disetujui, saldo terpotong, dan hari cuti otomatis masuk rekap.

06

Pengajuan Lembur

Lembur dihitung dari jam selesai shift + grace; tarif per jam dari pengaturan. Karyawan melihat estimasi rupiah sebelum mengirim.

8 layar
1KARYAWAN · APK ANDROID

Form Lembur

Tarif per jam & aturan pembulatan dijelaskan di atas form. Tanggal default hari ini.

→
2KARYAWAN · APK ANDROID

Pilih Jam

Pemilih jam native. Mendukung shift malam yang lewat tengah hari — jam pulang 06.00–09.00 dihitung ke hari berikutnya.

→
3KARYAWAN · APK ANDROID

Estimasi Rupiah

3 jam × Rp 20.000 = Rp 60.000 tampil langsung. Angka final dihitung ulang server saat dikirim.

→
4KARYAWAN · APK ANDROID

Lembur Terkirim

Durasi, nominal, dan status PENDING_HRD dikonfirmasi ke karyawan.

→
5KARYAWAN · APK ANDROID

Menunggu HRD

Riwayat › Lembur menampilkan tanggal, jam, nominal, dan status.

→
6HRD/ADMIN · DASHBOARD WEB

Approval HRD / GM

Alur approval berjenjang sesuai pengaturan (HRD, lalu GM jika nominal melewati ambang). Kolom Detail pengajuan menampilkan tanggal, jam mulai–pulang, keterangan, dan estimasi rupiah langsung di baris.

→
7KARYAWAN · APK ANDROID

Notifikasi Keputusan

Lembur disetujui oleh HRD — karyawan tahu tanpa perlu bertanya.

→
8KARYAWAN · APK ANDROID

Tercatat Disetujui

Nominal lembur yang disetujui otomatis masuk rekap payroll bulan berjalan.

07

Pengajuan Reimbursement

Alur lengkap sampai dibayar: karyawan mengajukan dengan bukti struk (1–3 foto) → HRD minta revisi → karyawan perbaiki & kirim ulang → approval berjenjang HRD → Finance → GM → Finance menandai dibayar.

20 layar
1KARYAWAN · APK ANDROID

Form Reimbursement

Kategori (Transport / Makan / Medis / Lain), nominal, tanggal pengeluaran, keterangan.

→
2KARYAWAN · APK ANDROID

Form Terisi

Nominal diformat rupiah otomatis. Tombol kirim nonaktif sampai struk dilampirkan.

→
3KARYAWAN · APK ANDROID

Struk Terlampir

Ambil foto langsung atau pilih dari galeri. Maks 2 MB per foto, dikompres di perangkat.

→
4KARYAWAN · APK ANDROID

Reimbursement Terkirim

Nominal, jumlah struk, dan status PENDING_HRD dikonfirmasi.

→
5KARYAWAN · APK ANDROID

Menunggu HRD

Riwayat › Reimburse: kategori, tanggal, nominal, jumlah struk, status.

→
6HRD/ADMIN · DASHBOARD WEB

HRD Minta Revisi

HRD memeriksa struk langsung dari thumbnail di kolom Detail pengajuan (klik untuk perbesar) — tanpa buka layar lain. Bila kurang jelas, HRD memilih Minta Revisi dengan catatan — bukan langsung menolak. Pengajuan tidak hangus.

→
7KARYAWAN · APK ANDROID

Notifikasi Perlu Revisi

Catatan HRD sampai ke karyawan apa adanya: “Foto struk kurang jelas, mohon unggah ulang…”.

→
8KARYAWAN · APK ANDROID

Status Perlu Revisi

Di Riwayat, pengajuan berstatus Perlu revisi menampilkan catatan approver dan tombol Perbaiki & kirim ulang.

→
9KARYAWAN · APK ANDROID

Form Revisi

Form terisi otomatis dari pengajuan lama + catatan approver di atas. Karyawan cukup memperbaiki bagian yang diminta.

→
10KARYAWAN · APK ANDROID

Unggah Struk Baru

Foto lama tetap dipakai bila tidak diganti; foto baru menggantikan semua foto lama — approver tidak perlu menebak mana yang berlaku.

→
11KARYAWAN · APK ANDROID

Revisi Terkirim

Status kembali PENDING_HRD; siklus approval otomatis mulai lagi dari langkah pertama.

→
12KARYAWAN · APK ANDROID

Menunggu HRD Lagi

Pengajuan yang sama (bukan pengajuan baru) kembali antre — jejak revisi tersimpan di audit log.

→
13HRD/ADMIN · DASHBOARD WEB

HRD · Langkah 1/3

Pengajuan hasil revisi muncul lagi di antrian HRD dengan langkah 1/3. HRD menyetujui.

→
14HRD/ADMIN · DASHBOARD WEB

Finance · Langkah 2/3

Giliran Finance: memeriksa nominal & struk, lalu menyetujui. Setiap langkah hanya terlihat oleh role yang berhak.

→
15HRD/ADMIN · DASHBOARD WEB

GM · Langkah 3/3

Giliran GM/Direktur sebagai langkah terakhir. GM/Admin juga punya Override untuk keputusan final darurat (alasan wajib).

→
16KARYAWAN · APK ANDROID

Notifikasi Tiap Langkah

Karyawan menerima notifikasi di setiap keputusan: disetujui HRD, Finance, lalu GM — lengkap dengan nama pemberi keputusan.

→
17KARYAWAN · APK ANDROID

Status Disetujui

Setelah 3 langkah selesai, status menjadi Disetujui dan masuk daftar pembayaran Finance.

→
18HRD/ADMIN · DASHBOARD WEB

Finance · Daftar Pembayaran

Menu Pembayaran reimbursement berisi semua pengajuan APPROVED yang belum dibayar, lengkap dengan foto struk.

→
19HRD/ADMIN · DASHBOARD WEB

Tandai Dibayar

Finance mengisi metode & tanggal bayar. Setelah PAID, pengajuan terkunci permanen (PRD §4.4) dan masuk rekap payroll.

→
20KARYAWAN · APK ANDROID

Status Sudah Dibayar

Karyawan melihat status akhir Sudah dibayar di Riwayat — alur selesai.

08

Notifikasi, Profil & Pengaturan

Semua keputusan terkumpul di satu tempat, dan karyawan mengelola akunnya sendiri tanpa bantuan HRD.

6 layar
1KARYAWAN · APK ANDROID

Notifikasi

Riwayat aktivitas: pengajuan terkirim, disetujui, ditolak, perlu revisi — dengan titik warna per jenis.

→
2KARYAWAN · APK ANDROID

Filter Tanggal

Saring notifikasi per rentang tanggal untuk karyawan dengan banyak aktivitas.

→
3KARYAWAN · APK ANDROID

Profil Karyawan

NIK, jabatan, site; akses ke Pengaturan, Ubah kata sandi, dan Keluar.

→
4KARYAWAN · APK ANDROID

Pengaturan

Bahasa Indonesia / English dan tema Terang / Gelap / Ikut sistem — pilihan tersimpan di perangkat.

→
5KARYAWAN · APK ANDROID

Ubah Kata Sandi

Wajib memasukkan sandi lama; sandi baru minimal 8 karakter. HRD juga bisa reset paksa dari dashboard.

→
6KARYAWAN · APK ANDROID

Keluar

Konfirmasi sebelum keluar; sesi di server ikut dicabut.
