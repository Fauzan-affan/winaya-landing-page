Kepemilikan

Yang Berpindah Tangan Bukan Lisensi, Tapi Software-nya Itu Sendiri

Inilah arti software HR beli putus dengan source code HRIS diserahkan penuh:

  • Source code & dokumentasi lengkap, milik Anda selamanya, bukan dilisensikan bulan per bulan.
  • Hak pakai perpetual, tanpa biaya per-seat, tanpa perpanjangan, tanpa tanggal kedaluwarsa. HRIS perpetual license dalam arti sebenarnya.
  • Bebas modifikasi atau menyewa siapa pun untuk maintain, Anda tidak pernah bergantung pada satu vendor.
  • Jalan di server yang Anda kontrol sendiri, tidak ada pihak lain yang bisa menghentikan layanan atau menaikkan harga di kemudian hari.

Satu-satunya batasan: software tidak boleh dijual ulang atau didistribusikan ke pihak lain.
